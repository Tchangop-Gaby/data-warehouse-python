# Data Warehouse Engineering Project

## Overview

This project implements a batch data warehouse pipeline using:

- Python
- Pandas
- PostgreSQL
- SQLAlchemy
- Pytest

## Source Data

The pipeline processes six CSV files:

- cust_info
- prd_info
- sales_details
- CUST_AZ12
- LOC_A101
- PX_CAT_G1V2
